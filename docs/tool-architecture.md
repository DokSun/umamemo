# 도구 확장 구조 (v1.1.0)

## 화면
- 단독: 선택 도구 1개를 전체 작업 영역에 표시.
- 동시: 이벤트 카운팅을 고정하고 선택한 보조 도구를 다른 패널에 표시.
- 화면 좌우 전환 및 비율 5:5 / 6:4 / 7:3. 작은 화면은 세로로 쌓음.
- 화면 설정은 `uma-tracker-layout-v1`에 저장되며, 기존 서버별 카운팅 데이터와 별개임.

## 도구 등록
현재 `app.js`의 `TOOLS` 목록에 도구의 고유 ID, 이름, 데이터 범위(scope), DOM 패널 ID(element), 초기화 메서드(reset)를 등록.
도구의 HTML 패널을 `#workspace` 내부에 하나 더 추가하면 화면 관리에서 표시 여부를 제어할 수 있음.
현재 도구는 `counter`(session)와 `memo`(independent).

## 초기화 규칙
- `session`: 한 번의 육성과 함께 초기화할 진행 기록.
- `independent`: 현재 육성에 종속되지 않는 작업 데이터.
- 현재 **표시된** 도구만 초기화 대상으로 지정.
- 동시 사용 도구 둘 다 session이면 통합 버튼 하나를 표시하며 각 도구의 `reset()`을 호출.
- 서로 다른 범위라면 도구별 초기화 버튼을 분리.
- 단독 모드에서는 해당 도구의 초기화 버튼 하나를 표시.
- 새 도구의 `reset()`은 **도구의 진행 기록만** 지워야 하며 보존할 설정·프리셋 등을 지워서는 안 됨.

## 상태 보존
- 기존 이벤트 카운팅: `uma-tracker-v1` / `uma-tracker-v1-jp` (기존 키 유지).
- 편성 세트: `uma-tracker-presets-v1` / `uma-tracker-presets-v1-jp` (기존 키 유지).
- 메모: 기존 상태의 `scenario` 필드 유지.
- 이후 기능은 각자의 로컬 저장 키를 사용하여 도구 간 기록을 덮어쓰지 않게 구현.
- 별도 공통 데이터 접근이 필요하면 명시적인 공유 인터페이스를 마련하며 다른 도구 내부 상태를 직접 변경하지 않음.

## 다음 단계 시 유의사항
- 평가점 계산기 등 큰 도구는 독립 화면에서도 완전하게 동작하는 반응형 레이아웃으로 구현.
- 각 도구가 필요로 하는 화면 크기와 입력 UI를 독립적으로 작성.
- 신규 session 도구가 추가될 때 기존 통합 초기화가 실제로 함께 호출되는지 시험.
- 최초 버전 보존 브랜치 `archive/v1.0.0-initial`은 수정하지 않음.
